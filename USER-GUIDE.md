# Ikonex Academy Student Management System - User Guide

## Accessing the System

Open the hosted application URL in your web browser.

## Dashboard

The dashboard provides:

* Total Students
* Total Streams
* Total Subjects
* Total Score Entries
* Recent Students
* Stream Summary

## Managing Streams

1. Open Class Streams.
2. Click Add Stream.
3. Enter stream details.
4. Save.

You can also edit and delete streams.

## Managing Subjects

1. Open Subjects.
2. Click Add Subject.
3. Enter subject information.
4. Assign the subject to a stream.
5. Save.

## Managing Students

1. Open Students.
2. Click Add Student.
3. Enter student details.
4. Assign a stream.
5. Save.

Students can also be edited and deleted.

## Recording Scores

1. Open Scores.
2. Select a student.
3. Select a subject.
4. Enter marks.
5. Save.

Scores can be edited and deleted.

## Results Processing

1. Open Results.
2. Select a stream.
3. View totals, averages, grades, and rankings.

## Reports

1. Open Reports.
2. Select a student or class.
3. Generate report.
4. Print or Save as PDF.

## Technologies Used

* CSS
* JavaScript
* Node.js
