Ikonex Academy Student Management System - Frontend Only

How to run:
1. Open index.html in your browser.
2. Use the sidebar to move between pages.
3. Data is saved in browser localStorage.

Pages:
- index.html: Dashboard
- pages/streams.html: Class streams
- pages/subjects.html: Subjects
- pages/students.html: Students
- pages/scores.html: Assessment scores
- pages/results.html: Results and ranking
- pages/reports.html: Student and class reports

Folders:
- css/style.css: all styling
- js/app.js: shared frontend logic
