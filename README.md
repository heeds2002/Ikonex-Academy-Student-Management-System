# Ikonex Academy Student Management System

## Overview

The Ikonex Academy Student Management System is a web-based application designed to manage students, streams, subjects, assessments, results, and reports in a school environment.

The system provides an easy-to-use interface for administrators to manage academic records and generate reports efficiently.

## Features

### Dashboard

* Total Students
* Total Streams
* Total Subjects
* Total Score Entries
* Recent Students
* Stream Summary

### Class Stream Management

* Create Streams
* Edit Streams
* Delete Streams
* View Streams

### Student Management

* Register Students
* Assign Students to Streams
* Edit Student Records
* Delete Students

### Subject Management

* Create Subjects
* Assign Subjects to Streams
* Edit Subjects
* Delete Subjects

### Assessment and Scoring

* Record Student Scores
* Edit Scores
* Delete Scores

### Results Processing

* Calculate Totals
* Calculate Averages
* Assign Grades
* Student Ranking
* Class Positions

### Reports

* Student Report Cards
* Class Performance Reports
* Print and Save Reports
